# Recursos JavaScript do RPO

O exemplo não redistribui bibliotecas de terceiros. Cadastre no RPO, preservando
as licenças originais, recursos com estes nomes:

- `twebchannel.js`
- `JsBarCode.all.min.js`
- `html2canvas.min.js`
- `jspdf.umd.min.js`

O fonte os obtém com `GetApoRes()`, incorpora as bibliotecas somente no HTML
hospedeiro e compartilha os objetos JavaScript necessários durante a geração.

Versões validadas no projeto de origem devem ser preferidas. Antes de produção,
verifique hashes, licenças e compatibilidade das versões adotadas.
